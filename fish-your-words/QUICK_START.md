# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Navigate to Project
```bash
cd /workspace/fish-your-words
```

### Step 2: Install Dependencies (if not done)
```bash
npm install
```

### Step 3: Run the Game
```bash
npm run dev
```

Then open your browser to: **http://localhost:5173**

---

## 📦 Available Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |

---

## 🎮 Game Controls

1. **Click & Hold** near the boat area (top of screen)
2. **Drag** your mouse to aim the fishing hook
3. **Release** to cast the line
4. **Catch** fish with letters to spell the target word

---

## 🎯 Game Objective

- Spell as many words as possible in **100 seconds**
- Catch letters **in sequence** to spell the target word
- Earn **stars** for each correct letter and completed word
- Avoid wrong letters to preserve your **3 hearts**
